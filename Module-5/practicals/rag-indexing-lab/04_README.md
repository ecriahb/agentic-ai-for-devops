# RAG Query Pipeline Practical

This lab implements the Lesson 02 query pipeline step by step:

1. Query Validation
2. Query Embedding
3. Candidate Retrieval / FAISS Search
4. Quality Gate
4B. No-Context / Evidence Sufficiency
5. Context Builder
6. Grounded Prompt
7. LLM Generation with Ollama
8. Validation

Local model used in the current lab: `qwen3:0.6b`.

The indexing side is represented by the companion indexing lab.
